# Waiting Kills — Premium Specialty Coffee

A responsive, multi-page HTML/CSS/JavaScript portfolio concept.

## Files
- `index.html` — homepage
- `menu.html` — menu with category filters and a local demo cart
- `story.html` — brand story and values
- `visit.html` — location concept and demo booking form
- `style.css` — shared responsive design system and animations
- `script.js` — navigation, reveal effects, demo cart, and form interactions

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension (if you don't already have it).
3. Right-click `index.html` and choose **Open with Live Server**.
4. Navigate through the site using the top navigation.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Before presenting it as a real client project
- Replace the concept address, hours, email, and social links with verified details.
- Replace sample menu and prices with approved information.
- The booking form is front-end only and does not send reservations.
- The menu cart is a local demonstration and does not process orders or payments.
- Images load from Unsplash and Google Fonts load from Google Fonts, so internet access is needed.
- Confirm image licensing and usage terms before commercial deployment.
- Connect a backend/service before enabling real bookings, orders, or payments.
